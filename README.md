## 🚀 خطوات الإعداد والربط

### 1. رفع الملفات على GitHub

1. أنشئ ريبو جديد على GitHub (مثلاً `tazweed-hub`)
2. ارفع جميع الملفات: `index.html`, `style.css`, `app.js`, `Price.xlsx`
3. فعّل **GitHub Pages** من Settings → Pages → Source: `main branch`

### 2. تحديث رابط Excel في app.js

افتح `app.js` وعدّل السطر التالي:

```javascript
// قبل:
const EXCEL_URL = 'https://raw.githubusercontent.com/YOUR_USERNAME/YOUR_REPO/main/Price.xlsx';

// بعد (مثال):
const EXCEL_URL = 'https://raw.githubusercontent.com/ahmed123/tazweed-hub/main/Price.xlsx';
```

### 3. تحديث رقم الواتساب

في `app.js` ابحث عن `966500000000` واستبدله برقمك الحقيقي:

```javascript
const waUrl = `https://wa.me/966XXXXXXXXX?text=...`;
```

## 📊 تنسيق ملف Price.xlsx

| العمود | الاسم | الوصف |
|--------|-------|-------|
| A | S | كود الفئة: E=محرك، C=تبريد، S=تعليق، P=قوة، A=جمالية، M=صيانة |
| B | Code | كود المنتج الفريد |
| C | Name | اسم المنتج |
| D | Price (SAR) | السعر الأصلي |
| E | Offer 20% | السعر بعد الخصم |
| F | Image URL | رابط صورة المنتج (اختياري) |

> الصف الأول = عناوين، المنتجات تبدأ من الصف الثاني
